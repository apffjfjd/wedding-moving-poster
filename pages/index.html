셀프 웨딩 무빙 포스터

구글 드라이브 폴더에 사진만 넣으면, URL 하나로 결혼식장에서 사진 슬라이드쇼를 무한 재생합니다. 영상 편집·렌더링이 필요 없습니다.

Drive API 키가 아직 설정되지 않았습니다. pages/config.js의 apiKey를 채우거나 빌드 시 DRIVE_API_KEY를 지정해야 재생됩니다. (README 참고)

1. 사진 폴더 준비

  1. 구글 드라이브에서 새 폴더를 만들고 사진을 넣습니다. (JPEG·PNG·WebP 등, 폰에서 올려도 됩니다)
  2. 폴더 우클릭 → 공유 → 일반 액세스를 "링크가 있는 모든 사용자", 역할은 뷰어로 설정합니다.
  3. 폴더 우클릭 → 링크 복사. 아래 "사진 폴더 링크"에 붙여넣습니다.

링크를 아는 사람은 누구나 폴더의 사진을 볼 수 있습니다. 예식이 끝나면 공유를 해제하세요.

2. 배경음악 폴더 준비 (선택)

사진과는 완전히 다른 폴더를 하나 더 만들어 음악 파일(MP3·OGG·WAV·M4A)을 넣습니다. 여러 개를 넣으면 이름순 첫 번째만 재생됩니다. 위와 같은 방법으로 "링크가 있는 모든 사용자 - 뷰어"로 공유하고 링크를 복사합니다. 배경음악이 필요 없으면 이 단계는 건너뛰어도 됩니다.

브라우저 자동재생 정책 때문에, 결혼식장 PC에서도 화면을 클릭하거나 F 키를 눌러야 소리가 납니다(전체화면을 켜는 동작과 같습니다). 재생 중에는 화면 오른쪽 아래 버튼으로 음소거할 수 있습니다.

3. 재생 URL 만들기

재생 열기

결혼식장 PC에서 이 주소를 열고 클릭하거나 F 키로 전체화면을 켜세요. 이후 폴더에 사진/음악을 넣거나 빼면 약 30초 안에 반영됩니다. 이 주소를 즐겨찾기해 두면 다시 만들 필요가 없습니다.

4. 파일명으로 효과 고르기 (선택)

사진은 파일명 순서로 재생됩니다(2가 10보다 먼저). 파일명에 효과 이름을 밑줄(언더바)로 이어 붙이면 그 사진에 해당 효과가 적용되고, 안 붙이면 자동입니다.
